## 🚀 Recent Critical Fixes (Summary)

- **Stabilization**: Introduced `ErrorBoundary` and fixed `NotFoundError` crashes.
- **SQL Ambiguity Fix**: Resolved persistent `column reference "id" is ambiguous` errors in `storage.ts` by explicitly qualifying table columns and using hardcoded prefixes in complex subqueries.
- **IKK Import Evolution**: Implemented a "middle ground" processing strategy:
  - Reduced parallel limit from 5 to 2 for module generation.
  - Added 2000-character text overlap in `splitPttIntoSections` to prevent data loss.
  - Granular extraction: Every bullet point is now a distinct module.
  - Sub-numbering: Implemented `3.x.x.a/b/c` section codes for deep curriculum structures.
- **Frontend Cleanup**: Automated module title cleaning to remove prepended chapter numbers, preventing UI duplication.

## 📌 Maintenance Rules for AI

1. **Always update the `docs/developer/task-log.md`** after significant changes.
2. **Refer to `docs/developer/prompts.md`** before changing IKK/Curriculum generation logic.
3. **Use the `scripts/data-integrity-check.ts`** if the user reports disappearing or ghost data.
4. **Never create redundant UI components**; check the `docs/developer/component-catalog.md` first.
5. **WARNING**: Google Translate MUST be disabled for the admin dashboard as it breaks React's DOM manipulation (NotFoundError: child not found). Use `lang="hu"` in HTML but avoid automatic browser translation.
