## 📌 Maintenance Rules for AI

1. **Always update the `docs/developer/task-log.md`** after significant changes.
2. **Refer to `docs/developer/prompts.md`** before changing IKK/Curriculum generation logic.
3. **Use the `scripts/data-integrity-check.ts`** if the user reports disappearing or ghost data.
4. **Never create redundant UI components**; check the `docs/developer/component-catalog.md` first.
5. **WARNING**: Google Translate MUST be disabled for the admin dashboard as it breaks React's DOM manipulation (NotFoundError: child not found). Use `lang="hu"` in HTML but avoid automatic browser translation.
